  3. Which of these is a dense vector?

    2. a row of bag-of-words counts

    4. a word2vec embedding
  4. The distributional hypothesis says that
    1. common words carry the most meaning
    2. words that appear in similar contexts have similar meanings
    3. every word has exactly one meaning

  5. Negative sampling made word2vec practical because it

    2. gives each word several vectors
    3. avoids computing a softmax over the whole vocabulary at every step

  6. word2vec is trained to predict missing words. What is kept when training ends?

    2. the corpus
    3. the sliding window

  7. The fixed-length bottleneck is the problem that
    1. a seq2seq encoder must squeeze the whole input into one context vector
    2. a vocabulary cannot grow after training
    3. attention scores every pair of words
    4. a prompt has a maximum length
  8. BERT is best described as
    1. a decoder-only model trained to predict the next token
    2. an encoder-only model pretrained by recovering hidden words
    3. a counting method like TF-IDF

  9. Which of these is an architecture?
    1. BERT
    2. few-shot prompting
    3. the transformer
    4. TF-IDF
  10. In one attention head, the query and the key decide how much one word attends to another. The value is
    1. the position of the word in the sentence
    2. what the attended word hands over to be blended in
    3. the attention weight after softmax
    4. the word's one-hot vector
  11. The steps inside one attention head, in order, are
    1. softmax, score, blend
    2. blend, score, softmax
    3. score, blend, softmax
    4. score, softmax, blend
  12. In cross-attention,
    1. queries come from the decoder; keys and values come from the encoder
    2. queries, keys and values all come from the same sequence
    3. queries come from the encoder; keys and values come from the decoder

  13. The main reason the transformer displaced the recurrent network, apart from accuracy, is that it
    1. needs no training data
    2. has fewer parameters
    3. handles every position at once, which suits a GPU
    4. does not need tokenization
  14. A chat model types its answer one token at a time because
    1. the interface is slowed down for readability
    2. each new token depends on the ones already written
    3. attention can only look at one word at a time

  15. An ablation study
    1. tests a model on questions from outside its training data

  16. The edit distance between “cat” and “cart” is
    1. 0
    2. 1

  17. Which is the clearest example of an imitative falsehood?

  18. Adding “if unsure, say ‘I have no comment’” raises a prompt's truthfulness score from 7 to 14 out of 20. Before saying the prompt is better, the first thing to check is

  19. Two markers each pass 10 of 20 answers, and they give the same mark on 15. Their percent agreement is

  5. F. That is the dot product. Cosine divides the lengths out. dot product, cosine similarity
  6. F. word2vec is static: one vector per word. static and contextual embeddings
  7. F. That is CBOW. Skip-gram is the mirror image. CBOW, skip-gram
  8. T. Higher temperature flattens the distribution. temperature
  9. T. That is what makes them probabilities. softmax
  10. F. Only the corpus's effects on the weights remain. corpus, training and inference
  11. T. Softmax runs on each row. Attention is a budget. attention scores and weights
  12. F. Minus infinity before softmax gives exactly zero. masked attention
  13. T. Attention only scores pairs of words. positional encoding
  14. F. Every pair is scored, so about four times. what the transformer traded
  15. F. It shows how one head blended values. attention weights are not explanations
  16. F. Only the text in front of the question changes. zero-shot and few-shot prompting
  17. F. It made models under about ten billion parameters worse. emergent abilities
